# Trouve ton artisan - Région Auvergne-Rhône-Alpes

Plateforme web de mise en relation avec les artisans de la région Auvergne-Rhône-Alpes.

## Prérequis
- Node.js (version 18+ recommandée)
- MySQL / MariaDB

## Installation et Lancement
1. Cloner le dépôt : `git clone https://github.com/Jo16000/trouve-ton-artisan.git`
2. Importer les scripts SQL de création et d'alimentation dans votre base de données MySQL.
3. Configurer les variables d'environnement (`.env`) dans le dossier back-end.
4. Lancer le Back-End : 
   ```bash
   cd backend_artisan
   npm install
   npm start
